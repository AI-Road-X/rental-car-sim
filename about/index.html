About RouteRiff

Most trip plans begin as text: an AI answer, a blog route, a spreadsheet or a list from a friend. RouteRiff is the visual layer that helps you see whether that plan makes geographic sense before you spend time and money booking it.

The workflow

Paste → See → Fix → Play → Share → Remix → Book

The current MVP deliberately stays narrow. It maps the stops you already have, estimates the rough travel load, flags obvious geographic problems, animates the route and creates a shareable link that another person can remix.

What it does not do

RouteRiff is not a travel agency, navigation system or live timetable. Exact transport, opening hours, visas, closures, weather and supplier terms must be checked with official sources.

Feedback

Found a bug or a route that behaves badly? Open a GitHub issue. If the underlying OpenStreetMap data is wrong, you can also report or fix the map data.
