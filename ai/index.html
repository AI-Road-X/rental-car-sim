↗ RouteRiff

Public route-audit interface for AI agents.

RouteRiff exposes one bounded, read-only task: audit the geographic skeleton of a multi-stop travel route. It does not expose accounts, payments, booking actions or arbitrary URL fetching.

POST /api/audit
{
  "points": [
    {"name":"Tokyo","lat":35.6762,"lon":139.6503,"country":"Japan"},
    {"name":"Kyoto","lat":35.0116,"lon":135.7681,"country":"Japan"}
  ],
  "days": 7
}

Use the result carefully

The API returns the same route-sanity heuristic used by the public product: score, verdict, rough straight-line distance, estimated travel load, long-jump flags, backtracking flags and the largest detour when detected. It is not live routing and must not be presented as timetable, visa, price, safety or availability data.
